# Transformation to log.index.flood

Computes the log-median (log.index.flood) from standard GEV parameters.

## Usage

``` r
reg.logmedian(mu, logsigma, k)
```

## Arguments

- mu:

  Numeric. Location parameter.

- logsigma:

  Numeric. Log-transformed scale parameter.

- k:

  Numeric. Shape parameter.

## Value

Numeric value representing the estimated log-index flood.
