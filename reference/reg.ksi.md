# Transformation to ksi

Computes the reparameterized shape parameter ksi from standard GEV
parameters.

## Usage

``` r
reg.ksi(mu, lsigma, k)
```

## Arguments

- mu:

  Numeric. Location parameter.

- lsigma:

  Numeric. Log-transformed scale parameter.

- k:

  Numeric. Shape parameter.

## Value

Numeric value representing ksi.
