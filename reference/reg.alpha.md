# Transformation to alpha

Computes the reparameterized scale parameter alpha from standard GEV
parameters.

## Usage

``` r
reg.alpha(mu, logsigma, k)
```

## Arguments

- mu:

  Numeric. Location parameter.

- logsigma:

  Numeric. Log-transformed scale parameter.

- k:

  Numeric. Shape parameter.

## Value

Numeric value representing alpha.
